# LS-Planer Politik

Werkzeug für das Fachteam Politik: Lernsituationen nach SchuCu-BBS 2024 und Unterrichtsverläufe mit einer KI planen, als Word-Datei speichern und in das iServ-Curriculum übertragen.

Aufruf: https://ls-generator.github.io

- Grundlagen: Rahmenrichtlinien Politik an berufsbildenden Schulen (2015), EB-BbS Nr. 3.9 (Niveaustufen)
- Die Seite lädt keine Inhalte von Drittanbietern. Eingaben bleiben im jeweiligen Browser.
- Die KI liefert Entwürfe; die fachliche Prüfung liegt bei der Lehrkraft.
